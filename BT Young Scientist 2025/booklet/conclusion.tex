\chapter{Conclusion}
I'm happy with how THOR turned out, and I learned a lot about Python, various programming concepts, using MQTT and Socket.IO, web programming, hardware programming, I\textsuperscript{2}C, UART, and drawing (see \autoref{chap:thoricons}), among a lot of other things, and I developed skills in time management, learning how to use unfamiliar programs/libraries (like \setmainfont{IBM Plex Serif}\LaTeX\setmainfont{IBM Plex Sans}\medspace and pillow), and I think I came out of this a better person than I was when I started. Because I didn't use AI at all for this project (not to challenge myself, but for ethical reasons), I feel I really understand how my project works and it makes me very proud of it.

As for the future of THOR, I think there's a lot of potential for the project should I choose to continue it. I intentionally designed it in such a way that allows me or anyone else to add sensors easily with programming knowledge. I'd like to make it easier to add more sensor types. I also want to learn 3D printing so I can make enclosures for the various nodes. I hope to make THOR a system one can easily and inexpensively install in their home, and I'd love if it could hook into other smart home systems like Home Assistant\footnote{Home Assistant already supports MQTT, so maybe it's  possible. I never tested it.}. I'd also like to be able to make alerts appear on mobile. I didn't do it this time because the Web Notifications API for JavaScript only works in secure contexts (HTTPS), which is inconvenient over a local network, and I don't have the skills, the money or the hardware needed to make an Android \textit{and} an iOS app.
