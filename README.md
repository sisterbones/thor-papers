This repository stores all of the related papers and documentation for THOR.

Most of this is written in LaTeX, intended to be compiled with LuaLaTeX. The backend for biblography should be `biber`. The BTYSTE2025 booklets are looking for `IBM Plex Sans` and `IBM Plex Mono` installed as TrueType fonts on your system (i.e. the regular way you install fonts).
